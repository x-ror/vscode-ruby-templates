Every check the language server runs reports its problems under a stable code, which is the name of its rule: `Html/ImgAlt`, `Syntax/Ruby`. In VS Code the code appears next to the message in the Problems panel and in the hover over the underlined text, with the language as the source (`erb`, `haml`, `slim`, or `ruby` for Jbuilder and Builder views). The `ruby-templates check` command prints the same messages as `file:line:column: severity: message`, without the code (`--format github`, `json` and `sarif` include it), and exits with 1 when it finds an error or a warning, or a problem in a `.ruby-templates.toml`.

The messages are those of Erubi, Rails, Haml 7, Slim 5 and Prism, or quote the section of the HTML standard that is broken. Each entry below shows a template that triggers the code and the message `ruby-templates check` prints for it, at the same line and column.

## Turning diagnostics off

Turn a check off in the `.ruby-templates.toml` of the project, by the rule's name (the code):

```toml
[Html.ImgAlt]
enabled = false

[Html.DuplicateId]
exclude = ["app/views/legacy/**"]

[haml]
disabled_diagnostics = ["Rails/MissingPartial"]
```

The file is read by the editor and by `ruby-templates check`, and it beats the settings below. The [rules reference](/vscode-ruby-templates/reference/rules/#configuration) describes the file.

Or list the codes to turn off for a language in your `settings.json`:

```json
"rubyTemplates.erb.disabledDiagnostics": ["Html/ImgAlt", "Html/DuplicateId"],
"rubyTemplates.haml.disabledDiagnostics": ["Rails/MissingPartial"]
```

Before 0.11 the codes were kebab-case words (`img-missing-alt`, `unresolved-render`). They still work in both places, and each entry below that had one names its earlier code.

`rubyTemplates.slim.disabledDiagnostics` also applies to Skim templates, and `rubyTemplates.jbuilder.disabledDiagnostics` to Jbuilder and Builder views. To silence a whole language, set `rubyTemplates.erb.diagnostics.enabled`, `rubyTemplates.haml.diagnostics.enabled` or `rubyTemplates.slim.diagnostics.enabled` to `false` (in a `.ruby-templates.toml`: `diagnostics.enabled = false` under `[erb]`, `[haml]` or `[slim]`). Liquid templates and Thor templates (`*.tt`) get no diagnostics.

The [rules reference](/vscode-ruby-templates/reference/rules/) lists the checks and formatter rules planned next, next to the ones that report these codes.
